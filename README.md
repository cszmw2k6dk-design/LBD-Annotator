# LBD 标注工具（LBD Annotator）

CAD-MAP 项目配套的标注小工具：在 PDF 图纸上框 LBD 区域 / 支架，**按框内文字自动补 LBD 编号**，
导出成主程序能直接用的 JSON。

## 运行

- **用现成的 exe**：到本仓库 Release 页下载 `LBD.exe`（就是 LBD标注工具，单文件、双击即可。
  GitHub 会把中文资产名简化成 `LBD.exe`，从 v0.4 起一直是这个名字）
- **源码直跑**：双击 `run_annotator.bat`（需要 Python 3.10+，并装好 PySide6 / pypdf）

## 主要功能

- 打开识别结果 JSON（agent3-debug 那种）或**直接打开 PDF 从零标注**
- **打开补标文件夹**（v0.39 起）：一个文件夹里每个 json 配一张同名图片（X-AnyLabeling /
  labelme 格式）也能直接审 —— 底图就用那张图片，工具栏「打开补标文件夹…」选中文件夹即可。
  里面的框**只含模型建议补的**（类别名带问号，如 `Node?` / `Typical?` / `Tracker?`），
  确认无误的留着、误检的删掉，Ctrl+S 就把改过的页**写回各自的 json**（图片和别的东西不动）。
  问号会原样保留 —— 合并回原始标注的脚本（`yolo26/merge_suggest.py`）靠它区分「建议框」。
  命令行也能直接传文件夹：`LBD标注工具.exe "D:\补标建议_v4c"`
- **起始页（按文件记）**：翻页控件旁边有「起始页」按钮 —— 点一下把当前页记成这份 JSON 的
  起始页，以后一打开就直接停在这一页（再点一次取消）。命令行也可以：
  `python lbd_annotator.py --start-page 20 "xxx.json"`
- 画框（两点确认 / 拖动都行）、改大小、改名字、删除、复制粘贴、撤销重做、翻页
- **自动补编号**：一键把一页/整册的 LBD 编号补上 —— 先读 PDF 文字层（原文、1~2 秒/页、
  不用装任何东西），**只有文字层没给到号的框**才自动渲染底图跑 OCR。整册算一步，Ctrl+Z 一次撤回
  - 补上的编号会连**位置**一起写进 JSON：`raw.label_pos` = [x, y]（页面像素，编号印在哪儿），
    `raw.label_src` = `text_layer`（读文字层）或 `ocr`（识别出来的）
    · 连**编号的小方框**也一起写：`raw.label_bbox` = [x1, y1, x2, y2]；名字那条记录
    （`ocr_node_name_results`）里也各有一份 `label_pos / label_bbox / label_src`
  - 工具栏「**编号框**」开关：在图上把识别到的编号位置画出来（橙色小方框 + 红色小十字），
    方便一眼核对"编号和框对不对得上"；只画当前页，默认开
- **按框内文字补 LBD 编号**：文字落在哪个框里就归哪个框；带 `LBD+编号` 的优先，其次裸数字（`07`），
  再兜底取文字里的数字段（`1.01.1.C.5` → 5）并和标签表号码表核对；拆开的、被截断的文字一律过滤
- 已有名字默认不动，需要覆盖时勾「重算(覆盖已有名字)」
- **导出核对表 CSV**：每个框一行（现有名字 / 框内候选 / 建议名字 / 来源）
- **OCR 读框内文字**：图纸里的字被转成矢量轮廓（选不中、没有文字层）时用这个 ——
  **只读 LBD 区域（Node）框里的字**，竖排标签自动旋正。按框本身裁图、**每 5 个框拼一张
  识别**（拼太多会串行读乱：30 块一张时 20 个框只读对 2 个，5 块一张 20/20）；没读到标准
  编号的框会自动单独重试一次。读到的写进名字，读到旁注（"LBD CLUSTER, TYP." 这种）不写
  名字、标红等人填，没读到的按「位置顺序 + 编号连续」推一个（标黄）。支架框（Tracker）
  不读、不写名字
- **锁定**：Node / 支架都能锁（本页一键锁 / 整册），锁上之后点不中、拖不动，
  识别和补编号也一律不碰它
- **用模型识别（YOLO）**：带进度条，范围可选本页 / 整册 / 指定页码（`3-8,12`）
- **支架按长度分档**：整册所有支架框一起按「长度差 ≤10% 算同一类」聚类，写进 JSON 的 `raw.strings`
  右侧栏会按分档统计「LBD 几 有多少串支架 / 一共多少串」
  - **每页比例尺不一样也没关系**：长度会先按**该页标题栏里的比例尺**（`1 IN = 100 FT` /
    标尺表 `1 2 IN` + `100 200 FT`）折算成英尺再比，并写进 `raw.length_ft`、
    `raw.page_scale_ft_per_in`。读不到比例尺的那几页会按整册最常见的比例算，并在弹窗里点名
- **导出 YOLO 数据集**：`images/` + `labels/` + `classes.txt` + `data.yaml`
- **训练环境面板**：探测本机 Python、检测/一键安装 `ultralytics`

## 打包

```bat
python 打包成exe.py             :: 单文件 exe（默认）
python 打包成exe.py --onedir    :: 文件夹版（不自解压，杀软误报率低）
python 打包成exe.py --console   :: 带控制台的调试版
```

## 依赖

- **PySide6**（界面）、**pypdf**（读 PDF 文字层）
- **poppler**（`pdftoppm.exe`，渲染 PDF 底图；放程序目录的 `poppler\` 下或加入 PATH 都认）
- 训练/推理另外需要 Python 环境里的 `ultralytics`

## 说明

- 设置文件和渲染缓存放在 `%LOCALAPPDATA%\LBD标注工具\`
- 杀软可能把打包出来的 exe 误报成木马（PyInstaller 常见现象），把 exe 所在目录加进信任区即可
